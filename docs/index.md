# ruin-theory

`ruin-theory` is a Python package for numerical and simulation work in ruin
theory. It is currently a public research preview: the API and documentation are
usable, but the package is still under active scientific review and should be
treated as under development.

The package includes classical Cramer-Lundberg formulas, finite-time discrete
recursions, prevention models, red-time diagnostics, Markov-modulated and
multirisk models, heavy-tail asymptotics, and reproducible validation examples.

## Status

- Development status: alpha / research preview.
- Target software-paper venue: Journal of Statistical Software, subject to
  review and fit.
- Validation approach: every implemented method should be tied to a source
  reference, a test, and a small reproducible numerical result.
- Private source PDFs and books are not part of the public package.

## Reviewer Rubric

Reviewers are asked to distinguish:

- mathematical correctness;
- API/usability;
- teaching value.
